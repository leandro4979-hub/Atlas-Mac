# Atlas-Mac

An original, lightweight macOS browser built with SwiftUI and WebKit. Not affiliated with OpenAI or ChatGPT Atlas.

## Features

- Multiple tabs
- Address/search field
- Back, forward, reload, stop
- Open current page in default browser
- Native macOS SwiftUI shell with WKWebView

## Open in Xcode

Open `Package.swift` in Xcode 16+ and run the `AtlasMac` executable scheme on **My Mac**. Requires macOS 14 or newer.

## Verify

```bash
swift build
```

## Security and scope

Web pages execute in WebKit. This prototype has no AI features, syncing, extensions, saved history, or automatic update system. It is not a clone of OpenAI's source code.
